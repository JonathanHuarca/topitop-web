# Topitop Web — Calidad Topitop & Combina tu look

Primer boceto interactivo de la plataforma web de **Topitop Perú**, enfocado en transparencia textil, trazabilidad por prenda con código QR y experiencia visual de combinación de outfits.

## Tecnologías
- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** + **QRCode** (generación de códigos QR reales vinculados por SKU)

## Funcionalidades principales
- **Calidad Topitop (Hecho para el Mundo)**: presentación de calidad de exportación, plantas en Lima y Chincha, certificación Oeko-Tex y experiencia en tienda (etiqueta QR, probador QR y tablet del asesor).
- **Combina tu look**: combinador visual para **Mujer, Niña, Hombre y Niño** con fotografías reales de prendas, capa exterior opcional, botón *Combinar al azar*, stock en vivo por talla, descuento automático **-10% por llevar el look** y opción de compartir por WhatsApp.
- **Ficha de producto, transparencia y trazabilidad**: acceso directo en la web (sin necesidad de escanear QR) con porcentajes de composición textil, procedencia de materias primas, proceso de fabricación, recorrido de trazabilidad en 4 etapas y código QR único vinculado por referencia SKU.
- **Catálogos, Tiendas, Buscador y Carrito deslizable**.

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Compilar para producción
```bash
npm run build
```
